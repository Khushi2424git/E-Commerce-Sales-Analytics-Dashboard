# 🛒 E-Commerce Sales Analytics Dashboard | Excel

## 📊 Project Overview

An Excel-based E-Commerce Analytics Dashboard designed to analyze sales performance, orders, customers, payment methods, delivery status, and customer reviews. The project transforms raw data into meaningful insights through KPI calculations, PivotTables, and interactive visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor order and customer metrics.
- Understand payment method preferences.
- Analyze delivery performance and order status.
- Explore customer review scores.
- Visualize business trends to support data-driven decisions.

## 📈 Dashboard Analysis

## 🚀 How to Use

1. Download or clone this repository.
2. Open `E-COMMERCE_DASHBOARD.xlsx` in Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Explore the KPIs, charts, and PivotTables.
5. Refresh the PivotTables after updating the source data, if applicable.
